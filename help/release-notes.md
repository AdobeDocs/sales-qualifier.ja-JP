# Sales Qualifier リリースノート

**08-17-2026**

[!DNL Sales Qualifier]はスタンドアロン アプリケーションとして利用できるようになりました。 当初はAdobe Journey Optimizer B2Bの一部としてリリースされました。

このリリースには次のものが含まれます。

* AIが生成したアクティビティの概要とシグナルベースのスコアリングによる、見込み顧客とアカウントの優先順位付け
* AIが提案したケイデンスとドラフトされたメールによる、目標主導型のエンゲージメントプラン
* 電話、LinkedInMails、メールレビュー用の統合タスクキュー
* カレンダー統合によるミーティングの自動予約
* 自社のプレイブック資料でAIのアウトリーチを促進するためのナレッジセンター
* CRM、エンゲージメント、ナレッジセンターのデータにもとづいて、自然言語での質問に対応するAI チャット
* 電子メールおよびミーティング予約のパフォーマンスレポート
* CRMまたはOutlook内でアクセスするためのブラウザーと電子メールのプラグイン
* SalesforceとMicrosoft Dynamics 365の統合のサポート
